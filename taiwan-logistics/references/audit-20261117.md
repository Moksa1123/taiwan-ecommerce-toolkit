# taiwan-logistics 官方文件稽核（2026-11-17）

對照各家物流服務商目前的官方 API 文件，找出 skill 內過時或錯誤的內容。只認官方來源（廠商開發者網站、官方規格書 PDF、官方 SDK／外掛）；沒有官方依據的不改，查不到的記進 `data/pending.csv`。

- 查證日期：除非另註，表內每一列都是 2026-11-17 查證
- 嚴重度：高＝會讓串接失敗（端點、簽章、必填欄位、代碼意義錯）；中＝欄位、代碼、版本資訊過時；低＝文字、連結
- 狀態：已改＝已修正；未改＝附原因
