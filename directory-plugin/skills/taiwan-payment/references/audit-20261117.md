# taiwan-payment 官方文件稽核（2026-11-17）

> 目錄精簡版：只含參考文件與 JSON 資料，不含腳本。文中提到 `scripts/`、`examples/`、`tests/` 的工具在完整版（npm 套件 `taiwan-payment-skill`）。
> 金鑰與商店代號由使用者自行設定、自行提供；文中的測試帳號是服務商官方公開的測試值，不是真實憑證。帳密類欄位以 `<帳密欄位>` 表示，實際欄名見官方文件。

對照各家金流目前的官方 API 文件，找出 skill 內過時或錯誤的內容。只認官方來源（廠商開發者網站、官方規格書 PDF、官方 SDK／外掛）；沒有官方依據的不改，查不到的記進 `data/pending.csv`。

- 查證日期：除非另註，表內每一列都是 2026-11-17 查證
- 嚴重度：高＝會讓串接失敗（端點、簽章、必填欄位、代碼意義錯）；中＝欄位、代碼、版本資訊過時；低＝文字、連結
- 狀態：已改＝已修正；未改＝附原因
